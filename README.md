# GENESIS — уровень 3: внешние данные

Отдельный репозиторий подключений внешних источников PISTOL GENESIS.
Адаптеры и источники вы добавляете самостоятельно. Сейчас здесь только контракт интеграции; датасетов и алгоритмов нет.

## Три уровня

| Уровень | Ответственность |
|---|---|
| 1 — ядро | Выполнение, временное состояние, метрики, перенос через checkpoint |
| 2 — [genesis-level-2](https://github.com/kirillpistol/genesis-level-2) | Алгоритмы и обучение |
| 3 — этот репозиторий | Получение и доставка внешней информации |

## Контракт адаптера

1. Получите одну запись из выбранного источника.
2. Отправьте JSON в ядро через `POST /tasks`.
3. Дождитесь ответа перед отправкой следующей записи.
4. После переноса ядра переключите адрес назначения на новый сервер.

Вход:

```json
{"algorithm":"your_algorithm","data":"информация из внешнего источника"}
```

data может быть числом, строкой, массивом, объектом, boolean или null.
Допустимый смысл и структуру определяет подключённый алгоритм уровня 2.

Ответ:

```json
{"algorithm":"your_algorithm","result":{},"revision":1}
```

result и revision в примере условные: реальный результат зависит от алгоритма, revision — от состояния ядра.

## Состояние и ограничения

`GET /status` показывает, подключён ли алгоритм, чего ждёт ядро и метрики обработки.
До отправки записей алгоритм должен быть подключён через `POST /algorithms/attach`.

Максимальный размер тела запроса задаётся в конфигурации уровня 1; по умолчанию 65536 байт.
Ядро не записывает исходные записи и результаты на диск. Адаптер сам отвечает за свои журналы, буферы и политику хранения.
Не кладите наборы данных, токены и пароли в Git.

При таймауте результат обработки может быть неизвестен. Автоматический повтор /tasks может повторно обучить алгоритм; exactly-once и очередь в ядре не реализованы.
Для соединения с защищённым ядром используйте Authorization: Bearer TOKEN; через недоверенную сеть используйте HTTPS-прокси или защищённый туннель.
